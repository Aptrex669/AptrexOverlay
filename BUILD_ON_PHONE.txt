BUILD THE APK USING ONLY YOUR PHONE (GitHub account required)

1. Sign in to github.com in your phone browser and create a new repository named AptrexOverlay.
2. Upload the CONTENTS of this ZIP into the repository (not the ZIP file itself). Keep the .github/workflows/build-apk.yml path.
3. Open the repository's Actions tab. The workflow named "Build Aptrex Overlay APK" starts after the first push. If it does not, open it and tap Run workflow.
4. When the run finishes successfully, open that run, scroll to Artifacts, and download AptrexOverlay-debug-apk.
5. Extract the downloaded artifact ZIP. Install app-debug.apk. Android may ask you to allow installation from your browser/files app.
6. Open Aptrex Overlay, grant Display over other apps, then tap Start floating menu.

This creates an unsigned debug APK for personal testing, not a Play Store release APK.
The switches in this app are visual only and do not control other apps or games.
